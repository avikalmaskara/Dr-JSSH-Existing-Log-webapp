# Dr. JSSH Existing Log

EON Sales web app for logging the air conditioners at the Dr. J.S.S.H site: tap-to-select floor/status/brand/tonnage,
compressed serial-number photos, a full-screen summary before submit, unique Log Nos (`JSSH/2627/0001`), and
a dashboard with edit history. Google Apps Script + Google Sheets, sign-in by emailed code.

See [docs/handover/dr-jssh-existing-log.md](docs/handover/dr-jssh-existing-log.md) and [AGENTS.md](AGENTS.md).
